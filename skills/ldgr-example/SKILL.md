# LDGR Example adapter

Use `ldgr example --help` to inspect the installed reference adapter. Use `ldgr example manifest-summary --json` to verify adapter-owned dispatch and manifest metadata. Core work remains under the normal one-ledger, one-active-run, one-bounded-work-item lifecycle.
